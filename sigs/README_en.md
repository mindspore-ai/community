# SIGs - Special Interest Groups

The MindSpore community is organized into different SIGs for better 
management and workflow improvement.

## SIGs Directory Structure

This directory stores operational information for all code repositories 
and Special Interest Groups (SIGs) within the MindSpore community.

Each subdirectory within this directory represents a SIG. 
Within each SIG, the SIG's description, maintainer, and managed code 
repository information are all located in the `sig-info.yaml` file.
