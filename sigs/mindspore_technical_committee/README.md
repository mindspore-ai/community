# 昇思MindSpore开源社区技术委员会

昇思MindSpore开源社区技术委员会是昇思MindSpore开源社区的技术领导机构，负责社区技术决策、技术资源协同调度，保障社区版本高质量发布。

## 组织会议

- 会议时间：北京时间，每月最后一个周五 上午，9:30~10:30
- 议题方向：
  1. 常设议题：遗留问题进展
  2. 常设议题：社区版本规划及进展
  3. 申报议题：SIG技术进展汇报或需求问题决策
  4. 申报议题：委员申报议题
- 议题征集：每次例会前2周面向委员及SIG Maintainer发起议题征集，会议前一周发布会议通知。
