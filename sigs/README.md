# SIGs - Special Interest Groups

SIG 全称是 Special Interest Group，即“特别兴趣小组”。
MindSpore社区按照不同的 SIG 来组织，以便更好地管理和改善工作流程。

## SIGs 的目录存储结构

本目录下存放的是 MindSpore 社区中，所有代码仓与特别兴趣 小组 （Special Interest Group，
以下简称 SIG）的运作信息。

本目录下每一个子目录，代表一个 SIG。 每个 SIG 的目录中，SIG 的 描述、maintainer 和 
管理的代码仓信息都位于 sig-info.yaml 文件中。
